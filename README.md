# ☕ Coffee House Management System

A modern coffee house management system designed to simplify daily coffee shop operations and improve business management.

## 🚀 Features

- Admin Dashboard
- Customer Management
- Product Management
- Menu Categories
- Order Management
- Payment Management
- Inventory Management
- Sales Reports
- Staff Management
- Database Integration

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL

## 📊 Main Modules

1. Dashboard
2. Products
3. Categories
4. Customers
5. Orders
6. Payments
7. Inventory
8. Reports
9. Staff
10. Settings

## 🎯 Project Purpose

This system helps coffee shop businesses manage customers, products, orders, payments, inventory, and daily sales efficiently.
